VERSÃO DE ARQUIVO ÚNICO PARA GITHUB PAGES

Este projeto tem somente um arquivo necessário: index.html.
A imagem está embutida dentro do próprio HTML (base64), então não existe pasta assets nem imagem externa para o GitHub perder.

PUBLICAR:
1. Crie/abra seu repositório no GitHub.
2. Envie o index.html para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch main e a pasta / (root), depois salve.
